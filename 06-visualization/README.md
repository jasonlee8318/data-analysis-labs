# 6강 — 시각화 및 리포팅 구성 (Power BI, Windows 전용)

8강에서 정제한 카페 매출 데이터를 **Power BI Desktop**으로 불러와,
**주별·월별 영업 실적 추이**를 직접 시각화합니다. 집계는 미리 해두지
않고, Power BI 안에서 직접 주/월 단위로 묶는 것 자체가 이번 회차의
핵심 실습입니다.

## 사전 준비

**Power BI Desktop** (Windows 전용, 무료): https://powerbi.microsoft.com/desktop/

## 1단계 — 대시보드용 데이터 내보내기

```powershell
cd export
python3 export_summary.py
```

8강의 정제 로직(결측치 처리, 중복 제거, IQR 이상치 제거)을 그대로
적용한 뒤, **하루 단위 그대로** `cafe_sales_clean.csv`를 생성합니다
(341행, 2026년 1~4월, 매장 3곳). 매장·요일 단위로 미리 뭉치지 않는
이유는, 그 집계 작업 자체를 Power BI에서 직접 해보기 위해서입니다.

## 2단계 — Power BI에 데이터 불러오기

1. Power BI Desktop 실행
2. 홈 탭 → **데이터 가져오기 → 텍스트/CSV**
3. `export/cafe_sales_clean.csv` 선택 → **로드**
4. 오른쪽 **필드** 창에 `store_id`, `date`, `weather`, `temp`, `weekday`,
   `customer_cnt`, `sales` 7개 컬럼이 보이면 성공

## 3단계 — date 컬럼을 진짜 "날짜" 타입으로 확인

1. **테이블 보기**(왼쪽 두 번째 아이콘)로 전환해 `date` 컬럼 클릭
2. 상단 **열 도구** 탭에서 **데이터 형식**이 **날짜**로 되어 있는지 확인
   (CSV를 그대로 불러오면 보통 자동으로 날짜로 인식됩니다)

이 타입이 "날짜"로 맞아야, 다음 단계에서 Power BI가 연/분기/월/일
계층을 자동으로 만들어줍니다.

## 4단계 — 월별 매출 추이 (꺾은선형 차트)

1. **보고서 보기**로 전환 → 시각화 창에서 **꺾은선형 차트** 선택
2. **X축**에 `date` 드래그
3. **Y축**에 `sales` 드래그 (기본으로 합계가 잡힙니다)
4. 차트 위에서 우클릭 → **드릴 다운** 또는 X축의 화살표를 눌러
   **연도 → 분기 → 월**로 내려가면, 자동으로 월별 합계 그래프가 됩니다

이게 Power BI의 **날짜 계층(Date Hierarchy)** 기능입니다 — 날짜 컬럼
하나만 있으면, 연/분기/월/일 단위 묶기를 코드 없이 클릭만으로 할 수
있습니다.

## 5단계 — 주별 매출 추이 (누적 세로 막대형 차트)

Power BI의 기본 날짜 계층에는 "주(Week)" 단위가 없어서, 이번엔 컬럼을
하나 직접 만들어봅니다.

1. **홈 탭 → Power Query 편집기** 열기
2. `date` 컬럼 선택 → 상단 **열 추가** 탭 → **날짜 → 주 → 주의 시작일**
   클릭 → `주시작일`이라는 새 컬럼이 자동 생성됨
3. **홈 탭 → 닫기 및 적용**으로 Power Query 편집기 나가기
4. 보고서 보기에서 **누적 세로 막대형 차트** 추가
5. **X축**에 방금 만든 `주시작일`, **Y축**에 `sales` 드래그

한 주의 시작일을 기준으로 매출이 자동 집계되어 막대그래프로 나타납니다.

## 6단계 — 매장별로 나눠보기 (슬라이서)

1. 시각화 창에서 **슬라이서** 추가
2. 필드에 `store_id` 드래그
3. 슬라이서에서 매장을 하나씩 클릭해보면, 4·5단계에서 만든 두 차트가
   그 매장 데이터만으로 다시 그려지는 것을 확인

## 7단계 — 저장

**파일 → 저장**으로 `.pbix` 파일로 저장합니다.

## 이 실습에서 확인해야 할 것

- 날짜 컬럼 하나로 연/분기/월 계층이 자동으로 만들어진다는 것(4단계)
- Power Query의 메뉴 클릭만으로 "주" 같은 새로운 집계 단위를 코드 없이
  만들 수 있다는 것(5단계)
- 슬라이서로 필터링하면 모든 차트가 함께 갱신된다는 것(6단계) — 이게
  "대시보드"와 "낱개 차트 모음"의 차이입니다

## 자주 겪는 문제

- **export_summary.py 실행 오류(FileNotFoundError)** → 반드시
  `06-visualization/export` 폴더 안에서 실행하세요 (8강 폴더를
  상대 경로로 참조합니다)
- **date 컬럼이 텍스트로 인식됨** → 테이블 보기에서 열 선택 후
  데이터 형식을 수동으로 "날짜"로 변경
- **꺾은선형 차트에 드릴 다운 화살표가 안 보임** → 차트를 한 번
  클릭해서 선택한 상태여야 X축 위에 위/아래 화살표가 나타납니다
- **한글이 깨져서 보임** → CSV는 이미 BOM 포함으로 저장되어 있어
  정상적으로는 발생하지 않습니다
- **다시 처음부터** → `export_summary.py`를 다시 실행해 CSV를
  새로 만들고, Power BI에서 파일을 다시 불러오면 됩니다
